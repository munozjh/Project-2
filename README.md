# ☕ Central Perk

A warm, responsive coffeehouse and bakery website inspired by the cozy 1990s sitcom *Friends*, built with **HTML5**, **CSS3**, and vanilla **JavaScript**, and deployed on **GitHub Pages** and **Netlify**.

## 🔗 Live Links

- **GitHub Pages**: [https://munozjh.github.io/Project-2/](https://munozjh.github.io/Project-2/)
- **Netlify**: [https://project2coffeeshop.netlify.app/](https://project2coffeeshop.netlify.app/)
- **GitHub Repository**: [https://github.com/munozjh/Project-2](https://github.com/munozjh/Project-2)

## ✨ Features

- **Multi-Page Navigation**: `Home`, `About`, `Menu`, `Gallery`, and `Contact` pages with shared header and footer
- **Interactive Menu Filtering**: Filter 14 items across `All Items`, `Specialty Coffee`, `Cupcakes & Muffins`, `Croissants`, `Sandwiches`, and `Fresh Juices` with a live item counter
- **Interactive Photo Gallery**: Filter 11 photos across `All Photos`, `Vibes & Team`, `Coffee & Juices`, and `Bakery & Bites` with a live photo counter
- **Contact Form Validation**: Client-side validation for name, email format, topic selection, and message length with live status feedback
- **Responsive Design**: Works across desktop, tablet, and mobile viewports
- **Custom Modular CSS**: Built with pure CSS (no external UI framework) and a warm `#FAF6F0` / `#3E2723` / `#C87D55` palette

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, CSS Grid & Media Queries)
- Vanilla JavaScript (DOM manipulation, filtering & form validation)
- GitHub Pages & Netlify
